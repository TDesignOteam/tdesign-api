## API

### ListItem Props

名称 | 类型 | 默认值 | 描述 | 必传
-- | -- | -- | -- | --
style | Object | - | 样式 | N
custom-style | Object | - | 样式，一般用于开启虚拟化组件节点场景 | N
action | String | - | 操作栏 | N
content | String | - | 内容 | N

### ListItem Slots

名称 | 描述
-- | --
action | 自定义 `action` 显示内容
content | 自定义 `content` 显示内容
