# 录入组件 API

通过终端命令将数据写入本地文件。

## 新增

`pnpm api:add --<options>`

执行前必须阅读 `pnpm api:add --help`。

## 更新

`pnpm api:update --<options>`

执行前必须阅读 `pnpm api:update --help`。

## 校验

`pnpm api:lint`

## 导出

`pnpm api:docs -- <component> '<framework>' [flags]`

执行前必须阅读 `pnpm api:docs -- --help`。
